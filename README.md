Entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun.

`main.py` (Python 3.13, standard library only) writes one original dad joke
to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR` when set):

> My smart fridge keeps suggesting recipes, but its meal plans are always half-baked.

Run it:

```sh
python3 main.py
```
